# Security Policy — Horizon OS

## Supported Versions
| Version | Supported |
|---------|-----------|
| 1.0 (Singularity) | Yes |

## Reporting a Vulnerability
If you discover a security vulnerability within Horizon OS, please report it confidentially via GitHub Security Advisories or by emailing the project maintainers directly.
Do not open public GitHub issues for undisclosed security vulnerabilities.
